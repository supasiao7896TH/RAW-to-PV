04 — วิธีใช้
เอาไปแปะยังไง
  1. 1

    คัดลอกโค้ดในกล่องด้านบนทั้งหมด (ตั้งแต่ <div class="soicoder-badge"> ถึง </style>)

  2. 2

    ไปที่โค้ดของแอป ShiftPro Tracker (หรือ session Claude Code ที่ทำแอปนั้นอยู่) หา footer badge เดิมที่ไม่ตรง mockup

  3. 3

    วางโค้ดนี้แทนที่ badge เดิม — ถ้าแอปมี CSS ของตัวเองอยู่แล้ว ย้าย <style> block ไปไว้ในไฟล์ CSS หลักได้ ไม่จำเป็นต้องอยู่ตำแหน่งเดิม

  4. 4

    ถ้าอยากให้ไม่พึ่ง Google Fonts CDN เลย (โหลดเร็ว/ออฟไลน์ได้) ให้ดูวิธี embed ฟอนต์เป็น base64 จาก index.html ในหน้า repo นี้เป็นตัวอย่าง

หมายเหตุ: session นี้เข้าไม่ถึงโค้ดของแอป ShiftPro Tracker โดยตรง (อยู่คนละ session/repo) หน้านี้จึงทำหน้าที่เป็น "ของที่ต้องยกไปเอง" แทนการแก้ให้อัตโนมัติ
